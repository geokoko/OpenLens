# ARGLASSES

A project dedicated to building a fully functional pair of smart glasses with an integrated facial emotion recognition pipeline and eventually its own operating system.

## Vision
The goal of this project is to create an end-to-end wearable system where:
- **Client (Raspberry Pi Zero 2 W):** Handles audio/video capture and feedback.
- **Server:** Processes complex AI tasks like emotion recognition and speech-to-text.
- **AI Integration:** Uses custom CNNs and LLMs to provide real-time assistance and context.

## Project Structure (Upcoming)
- `client/`: Raspberry Pi Zero 2 W implementation.
- `server/`: FastAPI backend for AI processing.
- `models/`: Trained neural networks for computer vision tasks.
